# Investigating-Suspected-Illegal-File-Transfer-From-Memory-Evidence

<h1>Gabriel - Investigating-Suspected-Illegal-File-Transfer-From-Memory-Evidence </h1>



<h2>Description</h2>
Examine the supplied Windows memory image with Volatility to reconstruct evidence of the suspected file-transfer activity. Submit an individual forensic report with labelled tool output or screenshots, an evidence log, and a UTC timeline. Work only on a copy, do not contact any endpoint or account in the evidence, and do not execute recovered files. Download the attached assessment brief for the full requirements..
